Traceability
============

These tables and tables are generated by Sphinx-Needs from the ``:tests:``
relationships -- nothing here is maintained by hand.

Coverage: each specification with the test case(s) that verify it
(``tests_back`` = incoming links). A specification with an empty cell here is
**uncovered**.

.. needtable::
   :filter: type == 'spec'
   :columns: id;title;tests_back as "Tested By"
   :style: table

.. needpie:: Specifications by number of linked tests
   :labels: Uncovered, 1 test, 2 tests, 3+ tests
   :legend:

   type == 'spec' and len(tests_back) == 0
   type == 'spec' and len(tests_back) == 1
   type == 'spec' and len(tests_back) == 2
   type == 'spec' and len(tests_back) >= 3

Tests: each test case with the specification(s) it verifies (``tests`` =
outgoing links). A test with an empty cell here is an **orphan**.

.. needtable::
   :filter: type == 'test'
   :columns: id;title;tests as "Tests"
   :style: table

.. needpie:: Tests by number of linked specifications
   :labels: Orphaned, 1 spec, 2 specs, 3+ specs
   :legend:

   type == 'test' and len(tests) == 0
   type == 'test' and len(tests) == 1
   type == 'test' and len(tests) == 2
   type == 'test' and len(tests) >= 3
